\# Bowling League Tracker - Project Plan



\## Project Overview



The Bowling League Tracker is a program designed to track individual bowler statistics, team performance, and season progress throughout a bowling league.



The project will also serve as a way for me to learn Python and practice designing a larger software project from the ground up.



## Main Goals



- Track bowling leagues

- Track teams within a league

- Track individual bowlers

- Record weekly bowling scores

- Calculate player averages

- Calculate team statistics

- Track season progress

- Save data so it is available after the program closes



## Version 1 Goals



The first version will focus on the basic functionality needed to manage one bowling league.



### League Management



- Create a league

- Store league information

- View league information



### Team Management



- Add teams to the league

- Add bowlers to teams

- View team rosters



### Bowler Management



- Store bowler names

- Record bowling scores

- Calculate individual averages

- Track games played



### Weekly Results



- Enter scores for each bowler

- Calculate series totals

- Update season averages

- Calculate team totals



### Data Storage



- Save league information

- Save team information

- Save bowler information

- Save scores between program sessions



## Future Features
